\begin{center}
	\textbf{\MakeUppercase{Mitigating Catastrophic Forgetting in Object Classification via Gaussian Class Representations
	}}
\end{center}

This research addresses the challenge of continual learning for object classification using Gaussian Modeling. It focuses on integrating foundation models as pretrained feature extractors with independent Gaussian models to characterize object classes. The main objective of this work is to develop and validate a continual learning framework for object classification, using pre-trained foundation models as features extractors and independent Gaussian models, with the purpose of enabling the incremental incorporation of new classes while preventing catastrophic forgetting of previously learned class. To achieve this, the study evaluates the effectiveness of various Gaussian representations and characterizes  the used methods. The proposed approach seeks to combine the independence of Gaussian models with the generalization capacity of foundation models as feature extractors, providing a scalable and efficient solution for dynamic environments where new object classes continuously emerge.

\begin{abstract}
Traditional deep learning architectures are predominantly monolithic, often failing to adapt when exposed to non-stationary data distributions. Incorporating new classes typically necessitates exhaustive retraining or fine-tuning on the entire dataset to prevent catastrophic forgetting, a constraint that limits their deployment in dynamic, real-world systems. To overcome these challenges, this work introduces a modular Continual Learning (CL) framework that decouples feature extraction from classification. By leveraging a frozen, pre-trained feature extractor paired with independent Gaussian models, we create distinct probabilistic representations for each class. This architectural decoupling allows for the seamless, incremental addition of new categories without interfering with previously acquired knowledge. Extensive evaluation on rigorous benchmarks ---including Split CIFAR-100, Split ImageNet-R, and Caltech-256--- demonstrates that our method achieves performance competitive with current state-of-the-art CL approaches. Furthermore, the results highlight that the proposed strategy is significantly more scalable, computationally lighter, and simpler to implement than existing replay-based or regularization-intensive methods, offering a robust solution for efficient continual learning.
\end{abstract}
