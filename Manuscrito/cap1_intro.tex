\chapter{Introduction}
\label{ch:intro}

\section{Motivation}

State-of-the-art (SOTA) object classification methods rely on deep learning models that are either trained end-to-end on the target application or initially trained on one task and subsequently fine-tuned for a different one. In both cases the resulting models are \emph{monolithic}: a single network is trained on a large dataset and performs feature extraction and classification jointly. Such models are highly effective when the set of object classes is fixed and known at training or fine-tuning time. When new object classes must be incorporated, however, the entire model must be retrained or fine-tuned. This procedure requires significant computational resources, demands access to the original training dataset and, in many cases, leads to \emph{catastrophic forgetting} of previously learned classes \cite{catastrophic}.

A natural way to integrate new classes while avoiding catastrophic forgetting is to formulate the problem as continual or class-incremental classification, in which the algorithm must learn to distinguish an ever-growing number of categories \cite{vandeVen}. In this paradigm, a \emph{task} corresponds to a distinct portion of the training experience, presented sequentially to the model. Instead of having access to the entire dataset at once, as in conventional supervised learning, the model receives data in sequential chunks \cite{taskarithmeticloracontinual}. Each task typically corresponds to a set of new classes that must be recognised. The central challenge is that when the model is updated task by task, it tends to overwrite previously acquired knowledge: monolithic models are structurally ill-suited for this scenario, and an alternative paradigm is therefore required.

This limitation has motivated the SOTA in continual classification to focus on balancing \emph{stability} and \emph{plasticity}. Stability refers to a model's ability to preserve previously learned knowledge; plasticity describes its capacity to adapt and incorporate new tasks \cite{API}. Traditional approaches rarely optimise both properties simultaneously: when stability dominates, the model struggles to integrate new knowledge; when plasticity dominates, it loses access to past information. This trade-off is compounded by the limited capacity of neural networks to integrate new representations without interfering with old ones and by the need to continually adjust the network's structure to match the growing number of object classes.

A natural way to overcome this dilemma is to decouple the monolithic model into two distinct components that are trained separately, possibly at different times: one responsible for feature extraction and another for object classification. The feature-extraction model must be trained at system-initialisation time and must produce embeddings that are general enough to characterise every class of interest, including classes unknown at training time. The classification model, by contrast, should be easy to update or extend as new object classes arrive, and ideally should be able to incorporate a new class without modifying the components that already recognise the existing classes. This structural separation mirrors the organisation of the human visual system, in which the structures responsible for low-level feature extraction (simple and complex cells in cortical areas V1 and V2) develop during the early post-natal weeks and remain largely stable thereafter \cite{Sluyters90}. High-level object recognition, in contrast, occurs in cognitive areas where the ability to learn new categories persists throughout life, occasionally producing slight degradation in the recognition of visually similar classes.

The emergence of large-scale, self-supervised visual foundation models (such as DINOv2 \cite{oquab2024dinov}) provides the empirical conditions to put this idea into practice. Foundation models offer general-purpose feature spaces with high transferability, and once frozen they yield a stationary representation in which incremental learning can be reduced to estimating class-conditional statistics rather than adapting network parameters. Building on this observation, we propose a continual learning object recognition system organised as two complementary components. The first component is a feature extractor built from a frozen pre-trained foundation model. The second component is a statistical classifier built from a collection of class-conditional Gaussian models, where each model characterises a specific object class independently of the others. A new Gaussian model can be created and inserted whenever a new class arrives, and classification is performed by assigning the input to the class whose Gaussian yields the highest log-likelihood, in direct analogy with a Bayes classifier.

Gaussian class representations offer two key advantages. First, each class is modelled independently from the rest, so incorporating a new class amounts to estimating a small number of sufficient statistics (mean and covariance) and does not require any modification of the previously stored class models. Second, Gaussian models are compact: they encode each class in a few parameters that can be estimated from a modest sample budget and refined as new samples become available, without any storage of the underlying images.

\section{Hypothesis}

This thesis hypothesises that the combination of an independent class-conditional Gaussian model and a frozen pre-trained feature extractor provides a robust framework for continual object classification. By enabling the addition of new classes without full-model retraining, this design eliminates the conventional source of catastrophic forgetting, while retaining a simple, compact and computationally inexpensive architecture whose accuracy and forgetting are competitive with the state of the art.

\section{General Objective}

The main objective of this thesis is to develop and validate a continual learning framework for object classification that uses pre-trained foundation models as feature extractors and independent class-conditional Gaussian models as classifiers, with the purpose of enabling the incremental incorporation of new classes while preventing catastrophic forgetting of previously learned ones.

\section{Specific Objectives}

For the purpose of fulfilling the general objective and verifying the hypothesis of this work, the following specific objectives are defined:

\begin{itemize}
	\item To assess the Gaussianity of the class-conditional feature distributions in the DINOv2 latent space, validating the underlying distributional assumptions of the proposed model.
	\item To characterise the efficacy of independent Gaussian distributions as class representations within a continual-learning framework, and to compare the result against prompt-based state-of-the-art baselines.
	\item To quantify the impact of various covariance-matrix estimators (diagonal, full, hybrid, shared, Ledoit--Wolf, OAS) and Mixture-of-Gaussian variants on the classification accuracy, the average forgetting and the probabilistic calibration of the resulting classifier.
	\item To design and evaluate a family of generative--discriminative fusion and re-ranking strategies that combine the Mahalanobis log-likelihood with auxiliary discriminative cues, and to identify which of them improve the baseline reliably and which are brittle.
	\item To analyse the probabilistic calibration of the proposed model through a comprehensive set of metrics (Expected Calibration Error, Confidence on Errors, Total Confidence, Log-Gap, predictive entropy) that go beyond raw accuracy.
	\item To evaluate the dependence of the framework on the choice of upstream feature extractor by comparing DINOv2 against supervised Vision Transformers of varying capacity (ViT-base/16, ViT-medium/16) across multiple benchmarks and incremental-learning scenarios.
\end{itemize}

\section{Contributions}

The principal contributions of this thesis are the following:
\begin{enumerate}
	\item A modular, gradient-free Bayesian continual-learning framework that decouples feature extraction from classification by combining a frozen DINOv2 backbone with independent class-conditional Gaussian models, achieving competitive accuracy and low forgetting without any rehearsal mechanism.
	\item A systematic comparison of covariance estimators in the high-dimensional, small-sample regime, including the introduction of a \emph{Hybrid} estimator that decouples the volume term (computed on the diagonal) from the shape term (computed on the full inverse). The Hybrid estimator is shown to dominate every alternative on the heavy-tailed and long-horizon benchmarks.
	\item A family of ten re-ranking and fusion strategies that integrate generative log-likelihood evidence with discriminative cosine similarity, log-domain task priors and temperature-scaled posteriors. An empirical taxonomy is derived from the results, separating these strategies into \emph{recommended}, \emph{brittle} and \emph{marginal}.
	\item A complete probabilistic-calibration analysis of the framework, including ECE, Total Confidence, Confidence on Errors, Log-Gap and predictive entropy across covariance estimators and benchmarks, with explicit identification of the volume--shape trade-off as the structural cause of the over-confidence observed under the Full-Covariance branch.
	\item A backbone-sensitivity study (DINOv2, ViT-base, ViT-medium) and a 30-task heterogeneous Joint benchmark that aggregates CIFAR-100, ImageNet-R and the first 250 categories of Caltech-256 into a single stream, providing the most demanding evaluation regime currently reported for closed-form Bayesian continual classifiers.
\end{enumerate}

\section{Thesis Structure}

The remainder of the document is organised as follows.

\paragraph{Chapter~\ref{ch:framework} -- Theoretical Framework.}
Establishes the mathematical and conceptual basis of the work. It reviews the relevant subset of artificial intelligence, deep learning and computer vision, presents Bayesian classification and the Mixture-of-Gaussian extension, introduces the high-dimensional covariance estimation tools (regularisation, Ledoit--Wolf and OAS shrinkage), discusses the empirical Gaussianity diagnostics (skewness, kurtosis, Mahalanobis distance) and surveys the continual-learning paradigm together with its dominant mitigation strategies.

\paragraph{Chapter~\ref{methodolohy} -- Methodology.}
Describes the proposed architecture and its components in detail. It defines the experimental protocol for the four benchmarks ---Split CIFAR-100, Split ImageNet-R, Split Caltech-256 (10 tasks of 25 classes each over the first 250 categories) and the 30-task Joint stream---, formalises the six covariance estimators and the Mixture-of-Gaussian variants, derives the ten generative--discriminative fusion and re-ranking strategies, discusses temperature-scaled Bayesian calibration and introduces the probabilistic metrics used in the evaluation.

\paragraph{Chapter~\ref{ch:results} -- Results.}
Reports the quantitative results of every experiment carried out in the thesis. It is structured by the same top-down logic used to validate the modelling pipeline: per-dimension Gaussianity moments, feature-space diagnostics (PCA spectral decay and Mahalanobis histograms), continual-learning metrics across covariance estimators, generative--discriminative fusion tables, backbone ablations, calibration metrics, and incremental class-inclusion curves. All interpretation is deferred to the next chapter.

\paragraph{Chapter~\ref{ch:analysis} -- Discussion and Analysis.}
Interprets the experimental evidence. It examines the statistical characterisation of the DINOv2 embedding space, compares the covariance estimators and mixtures under the volume--shape decomposition principle, evaluates the re-ranking family and identifies which strategies improve the baseline reliably, and discusses backbone sensitivity, calibration and the framework's computational footprint. The chapter closes with a synthesis of the principal findings and a practical recipe.

\paragraph{Chapter~\ref{ch:conclusion} -- Conclusion.}
Summarises the main conclusions of the work and outlines two natural extensions of the framework: open-world discovery (using the model's confidence as an out-of-distribution score) and real-time object detection (leveraging the spatial tokens of the DINOv2 backbone to avoid an external region-proposal network).
