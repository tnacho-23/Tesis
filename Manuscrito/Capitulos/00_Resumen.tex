 \begin{center}
 	MITIGACIÓN DEL OLVIDO CATASTRÓFICO EN LA CLASIFICACIÓN DE OBJETOS MEDIANTE REPRESENTACIONES GAUSSIANAS DE CLASES
 \end{center}
 
 \noindent Los modelos tradicionales de aprendizaje profundo suelen fallar cuando trabajan con datos que cambian en el tiempo, ya que incorporar clases nuevas exige un reentrenamiento costoso o provoca que el modelo olvide lo aprendido. Para resolver esto, se propone un método de aprendizaje continuo libre de gradientes enfocado en el reconocimiento visual. En lugar de optimizar parámetros, el sistema aborda la tarea estimando densidades en forma cerrada a partir de las representaciones de  un modelo fundacional como extractor de características congelado, modelando cada clase mediante una distribución gaussiana multivariada. Así, las clases nuevas se integran al instante, sin requerir retropropagación, almacenamiento de muestras, ni ajuste de parámetros. Además, como la información de las clases anteriores nunca se altera, se previene el olvido por diseño. Al evaluarse en benchmarks como Split CIFAR-100, Split ImageNet-R y Split Caltech-256, este enfoque logra un rendimiento competitivo frente a métodos que dependen de optimización de parámetros. Entre las configuraciones probadas, la variante MOG4-Shared —que combina una mezcla de gaussianas por clase con una covarianza compartida— logró el mejor desempeño. Finalmente, un análisis estadístico valida el supuesto gaussiano y muestra que la covarianza óptima depende de los datos disponibles por clase.

 \begin{center}
 	MITIGATING CATASTROPHIC FORGETTING IN  OBJECT CLASSIFICATION VIA GAUSSIAN CLASS REPRESENTATIONS
 \end{center}
 
 \noindent Traditional deep learning models struggle with non-stationary data, as adding new categories typically requires costly retraining or causes catastrophic forgetting. This thesis introduces a gradient-free, class-incremental learning framework that frames lifelong visual recognition as closed-form density estimation rather than parameter optimization. By pairing a frozen foundation model as backbone with per-class multivariate Gaussian models, new classes are integrated instantly without backpropagation,  storing past samples, or fine-tuning. Because existing class statistics remain untouched, the framework eliminates forgetting by design. Evaluated across benchmarks such as Split CIFAR-100, Split ImageNet-R, and Split Caltech-256, this approach achieves competitive performance against optimization-heavy method. Among the tested variants, MOG4-Shared—which combines a compact per-class mixture with a single shared covariance—provides the best trade-off between computational efficiency and accuracy. Finally, evaluating the feature space of the DINOv2 foundation model through normality tests, spectral analysis, and Bhattacharyya distances validates the Gaussian assumption for feature extraction and shows that the optimal covariance structure depends directly on sample availability per class.
