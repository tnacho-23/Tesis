\chapter{Results}

Our approach uses a pre-trained foundation model to extract features of images and generate Gaussian representations per class where, during the inference step, the classifier will predict the class that hast the highest likelihood among the existing Gaussians. Several Gaussian representations were developed: separable, non-separable, and Gaussian-mixture models using both separable and non-separable mixtures.

\section{Baselines Comparison}

We selected prompt-based methods, specifically L2P \cite{wang2022learning}, Dual Prompt \cite{wang2022dualprompt}, and CODA-Prompt \cite{Smith_2023_CVPR}, as our baselines. These methods utilize a ViT-B/16 \cite{AnImageIsWorth} as the backbone. For our experiments, we evaluated our model using two distinct backbones: the standard ViT-B/16 and a ViT-M/16 \cite{rw2019timm}. Both architectures were pre-trained on ImageNet-21k and subsequently fine-tuned on ImageNet-1k. The performance of these backbones on ImageNet-1k, using the original FFN classification head, is presented in Table \ref{tab:backbone_accuracy}.

Table \ref{tab:method_comparison} presents the experimental results on the CIFAR-100 and ImageNet-R datasets. While CIFAR-100 is class-balanced, ImageNet-R exhibits significant imbalance, with sample counts varying widely across classes. To address this, we applied a balancing strategy in select experiments, denoted by the suffix ``-B''. In these cases, synthetic samples were generated for under-represented classes by sampling from a Gaussian distribution defined by the class mean and covariance. Regarding the GMM-based methods, the suffix ``-S'' indicates the use of separable covariance, while ``-N'' denotes non-separable covariance. If no covariance suffix is present, non-separable covariance is implied.
