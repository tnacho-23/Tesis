\section{Proposed Architecture}
The proposed continual learning object recognition system is based on the following two components: (i) a feature extraction model built using a foundation model and (ii) a Gaussian classification model built using several Gaussians models, each characterizing a given object class independently of the other classes. For classification, the class whose Gaussian yields the highest likelihood of the Continual Object Learning using Gaussians input features is selected.
