\section{Proposed Architecture}

As shown in \ref{fig:architecture}, our CIL framework is built upon a simple yet structurally motivated decomposition: (i) a frozen feature extractor based on a visual foundation model, and (ii) a probabilistic classification layer that models each object category through an independent Gaussian distribution in the embedding space. Given an input image, the feature extractor maps it to a fixed high-dimensional representation. For each class, we maintain a class-conditional multivariate Gaussian characterized by its mean vector and covariance matrix, estimated incrementally from observed samples. Classification is performed according to the maximum likelihood principle, assigning the input to the class whose Gaussian model yields the highest likelihood under the stationary embedding representation. This modular separation between representation learning and statistical modeling enables incremental updates without backpropagation or parameter adaptation: adding a new class requires only estimating its distribution in the fixed feature space, while previously learned classes remain unaffected at the representation level.

\subsection{Mahalanobis Distance and Temperature Scaling}
The Mahalanobis distance is a scale-invariant metric that measures the distance between a point $x$ and a distribution with mean $\mu$ and covariance $\Sigma$.

\subsubsection{Distance and Likelihood Relation}

The squared Mahalanobis distance $D^2$ is:$$D^2 = (x - \mu)^T \Sigma^{-1} (x - \mu)$$For a multivariate Gaussian distribution, the log-likelihood is:
\begin{equation}
	\ln L(x) = -\frac{1}{2} \ln |\Sigma| - \frac{1}{2} D^2 - \frac{k}{2} \ln(2\pi)	
\end{equation}

This reveals that maximizing the log-likelihood is equivalent to minimizing the Mahalanobis distance (after accounting for the determinant of the covariance). This relationship is the basis for Mahalanobis-based classifiers, which are effective in high-dimensional embedding spaces where Euclidean distance fails to account for feature correlations.

\subsubsection{Calibration via Temperature Scaling}

Classifiers based on deep features often produce scores that are not well-calibrated probabilities. Temperature scaling is a post-processing technique that adjusts the log-likelihood scores before they are passed through a softmax function.The score for class $i$ is modified by a scalar $T > 0$:

\begin{equation}
	\text{Score}_i = \frac{1}{T} \left( \ln A_i - \frac{1}{2} D_i^2 \right)
\end{equation}

where $\ln A_i$ is the log-normalization constant. An optimal $T$ is typically learned using a validation set to minimize negative log-likelihood (NLL). $T > 1$ "softens" the distribution (reducing overconfidence), while $T < 1$ ``sharpens" it. This calibration is critical for tasks requiring reliable uncertainty estimation, such as out-of-distribution detection or safety-critical classification.
